# Language and culture protocol

## Translation chain

每条重要材料保留四个文本层：

1. `original_text`：当地语言原文。
2. `literal_translation`：尽量贴近字面含义的中文直译。
3. `semantic_interpretation`：语气、隐含前提、指代和语用解释。
4. `cultural_context`：当地习惯、制度、身份、场景或消费文化背景；如果没有证据，标记为假设。

不要把中文翻译中的“天然、方便、高级、性价比、温和”等词直接当作当地用户的同义概念。比较时注明词义范围、礼貌程度、讽刺/反话、俚语和行业术语。

## Sampling and bias

记录平台受众、语言、内容可见性、评分机制、时间窗口、重复样本、营销内容、极端评价和选择偏差。若样本集中于单一平台，聚合表必须显示 `platform_bias`，不能使用“当地消费者普遍”。

## Cross-validation

将用户主题与竞品价格/功能、搜索词、官方法规、退货/售后信号或多个平台材料对照。交叉验证支持“证据一致”，不等于证明因果关系。
