# Decision gates

## Gate 1: comparability

确认市场定义、品类边界、时间范围、币种、单位和样本分母一致；否则分列展示并解释不可比原因。

## Gate 2: user evidence

确认用户主题有原始内容、编码规则、样本数、平台数、时间范围和偏差说明。标准/深度研究若没有当地语言原文，不能给出高置信度文化结论。

## Gate 3: regulatory veto

确认分类、强制认证/注册、责任主体、标签/宣称、进口和消费者保护要求。未解决的禁售、不可合规或长周期高成本事项优先输出 `HOLD` 或 `NO-GO`。

## Gate 4: recommendation

用证据覆盖度、机会、竞争/渠道、用户需求、法规和经济性解释 `GO / NARROW / HOLD / PIVOT / NO-GO`。若证据不足，建议必须带最低补充数据和待复核来源。
