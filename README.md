# Aquria Brand Market Entry Skills

## 当品牌准备进入一个新市场

进入海外市场，真正难的通常不是找到一组市场规模数字，而是判断：

- 这个国家是否真的存在适合自己的机会？
- 当地用户为什么会买，为什么不会买？
- 中国市场验证过的产品和卖点，换到当地还成立吗？
- 当地的语言、文化、隐私、认证和销售规则，会不会改变进入方式？
- 哪些结论有数据支持，哪些只是暂时的判断？

`Brand Market Entry Skills` 是一套面向品牌出海前期研究的工作方法。它帮助团队把市场机会、用户洞察和法规要求放在同一张决策地图上，形成一份能够解释“为什么进入、为谁进入、如何进入、有哪些风险”的专业报告。

## 它解决什么业务问题

很多出海调研容易出现三种断裂：

1. 只看宏观市场数据，却不知道真实用户是否愿意购买；
2. 只翻译用户评论，却忽略当地文化、表达方式和使用场景；
3. 只在报告最后补充法规，等产品、渠道和营销方案确定后才发现无法合规落地。

这个 Skill 将三条线放在一起分析：

| 研究视角 | 重点回答的问题 |
|---|---|
| 市场与竞争 | 市场机会在哪里？需求、价格、竞品和渠道是否支持进入？ |
| 用户与文化 | 当地用户是谁？他们如何表达需求？国家特点和文化差异如何影响产品与传播？ |
| 法规与进入 | 产品、数据、营销、销售和售后有哪些必须满足的要求？ |

最终不是分别生成三份材料，而是把它们汇总成一个可以用于决策的结论：机会、限制、证据、风险和下一步行动。

## 适合哪些场景

它适合品牌在进入以下市场之前使用：

- 进入一个从未经营过的国家或区域；
- 将已有产品从中国市场复制到海外；
- 在多个国家之间选择优先进入市场；
- 评估一个新品类是否值得投入；
- 为经销商、电商、独立站或线下渠道选择进入路径；
- 在产品上市前提前识别认证、隐私、广告和消费者保护风险。

适用团队包括品牌创始人、海外业务团队、市场与产品团队、咨询顾问，以及需要把研究结果交给管理层讨论的项目负责人。

## 它能带来的价值

### 让进入判断更接近真实市场

不只引用宏观报告，也会结合当地用户内容、竞品信息、价格与渠道表现，帮助团队判断“市场看起来很大”和“品牌有机会进入”之间的差距。

### 让用户洞察不止停留在翻译

保留当地语言原文，结合语义、场景、文化背景和表达习惯分析用户内容，避免把中文语境中的经验直接套到另一个国家。

### 让法规成为进入策略的一部分

法规不再只是报告末尾的风险提示，而是前置影响产品功能、数据处理、广告表达、渠道选择和售后安排的进入条件。

### 让结论能够被复查和讨论

每个重要判断都尽量对应来源、样本、数据或推演过程；同时记录假设、反证、冲突和数据缺口，让团队知道哪些结论可以直接行动，哪些还需要验证。

### 让研究可以分阶段推进

团队可以先看研究范围，再分别审阅市场、用户和法规材料，最后合并成总报告。中途可以暂停、补充数据，或只重跑某一个模块。

## 一个典型例子

例如，一家安防摄像头品牌准备进入越南市场，不能只回答“越南有多少家庭或摄像头市场规模”，还需要同时了解：

- 家庭、小微商户和其他用户的真实安全场景；
- 越南用户如何搜索、比较和评价摄像头；
- 对云存储、远程查看、隐私和数据处理的接受程度；
- 当地语言、信任关系、价格敏感度和购买渠道；
- 无线设备、进口、认证、隐私和消费者保护等进入要求；
- 产品定位、功能组合、价格、渠道和传播信息是否需要调整。

这个 Skill 会把这些问题拆成可研究的任务，分别形成数据表、用户证据、法规清单和推演过程，最后汇总为一份可以支持进入决策的报告。

## 最终可以得到什么

研究可以按阶段交付，也可以一次性生成总报告：

| 阶段 | 你会看到的内容 |
|---|---|
| 研究定义 | 研究目标、品类边界、目标用户、关键问题和数据需求 |
| 市场与竞争 | 市场指标、需求信号、竞品、价格、渠道和进入机会 |
| 用户与文化 | 用户内容、语言差异、文化解释、用户分群和使用场景 |
| 法规与进入 | 产品、数据、广告、销售、进口和售后相关要求 |
| 证据综合 | 证据强弱、假设、冲突、风险、机会和决策建议 |
| 总报告 | 可阅读、可复查、适合分享和打印的 Markdown / HTML 报告 |

最终报告不会只给出一句“建议进入”或“不建议进入”，而会说明：

- 建议进入的依据是什么；
- 哪些用户和场景最值得优先切入；
- 产品、价格、渠道和传播需要如何调整；
- 进入前必须解决的法规与运营问题；
- 结论中仍然存在的未知数，以及如何进一步验证。

## 怎么使用

安装后，可以直接用自然语言描述你的研究任务，例如：

```text
请运行品牌出海市场进入研究：
品类：安防摄像头
国家：越南
目标用户：家庭、小微商户
目标：判断是否值得进入，并提出产品、价格、渠道和传播建议
研究深度：标准
输出：按阶段执行，每阶段先给我中间产物，我回复“继续”后再进入下一阶段
```

也可以提出更具体的问题，例如“只先做用户与文化模块”“补充法规研究”“重跑市场竞品模块”或“把已有材料汇总成最终 HTML 报告”。

## 研究模块

| Skill | 适合解决的问题 |
|---|---|
| `brand-market-entry` | 默认入口：从研究目标到最终报告的整体编排 |
| `market-regulatory-entry` | 市场、需求、竞品、价格、渠道和法规进入要求 |
| `user-cultural-insight` | 用户内容、语言差异、文化背景和用户证据 |
| `market-entry-synthesis` | 合并证据、检查冲突与缺口、形成进入建议 |

V1 内置美妆个护、包装食品/饮料、消费电子/小家电三类品类参考。其它品类也可以沿用同一套方法，根据产品特性增加数据来源、用户场景和法规要求。

## 安装

安装默认入口：

```bash
npx skills add Stella-Insight-Lab/brand-market-entry-skills --skill brand-market-entry --agent codex --global --yes
```

安装全部模块：

```bash
npx skills add Stella-Insight-Lab/brand-market-entry-skills --skill '*' --agent codex --global --yes
```

也可以下载仓库后，把需要的 `skills/<skill-name>/` 目录复制到兼容 Agent Skills 的目录。

## 输出结构

默认研究项目会按阶段保存材料：

```text
market-entry-project/
├── 00-brief/
├── 01-research-design/
├── 02-market-competition/
├── 03-user-cultural/
├── 04-regulatory-entry/
├── 05-evidence-synthesis/
├── 06-final-report/
└── runs/<timestamp>/
```

阶段材料包括 Markdown、CSV、JSON 和 HTML：Markdown 用于解释，表格用于复查数据，JSON 用于结构化传递，HTML 用于分享和打印。完整示例见 `examples/vietnam-security-camera/`。

## 重要说明

用户内容比例只表示当前采集样本中的分布，不自动代表国家总体。公开内容采集必须遵守来源平台条款、隐私要求、版权边界和合理访问频率。

本项目是研究工作流与证据组织工具，不提供正式法律意见、认证承诺或监管机构判断。法规结论应回到目标市场的官方法规库、监管机构、海关、认证机构或当地专业顾问复核。
